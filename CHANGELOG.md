## [0.6.0](https://github.com/bluesky-social/slagworks/compare/v0.5.0...v0.6.0) (2026-11-20)


### ⚠ BREAKING CHANGES

* a site worker now sends its token only in the Authorization header and global no longer reads it from the URL, so global and every site worker must be upgraded together. A worker on an older build cannot connect to a newer global, cannot learn its version, and will not auto-upgrade across this release: upgrade the worker packages by hand, then rotate the worker tokens. The MAC-only phone-home route is removed. Image names, kernel parameters, hostname templates and device names that fail the new validation are refused; see the rollout notes in the pull request.
